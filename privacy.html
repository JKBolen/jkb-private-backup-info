Privacy Policy

JKB Private Backup is operated for the account owner's personal use to protect server files and databases.

Google Drive access

The application requests the Google Drive drive.file permission. This permits it to create and manage files it creates or files the account owner explicitly makes available to it. It does not request access to all files in the account.

Use and protection of data

The tool encrypts backup data on the owner's server before sending it to the owner's Google Drive. The encryption key is kept on equipment controlled by the owner. Google stores encrypted backup content and can process associated metadata such as file sizes and transfer times. The tool does not use Google user data for advertising or sell it.

Google authorization credentials are stored in encrypted configuration on the owner's devices and are used only to run or restore the backup. Google is the storage provider; the backup operator does not otherwise share the data.

Retention, deletion and revocation

Backup snapshots are retained according to the owner's configured schedule. The owner can delete the application's backup files in Google Drive and revoke its access from the Google Account security settings. Losing the encryption key can make the backups impossible to restore.
